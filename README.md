# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount based on the annual rate of interest and the time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest
- Time period in years

## Example
- Principal: 1000
- Rate of interest: 5%
- Time: 2 years

Calculation: (1000 × 5 × 2) / 100 = 100

**Simple Interest = 100**

## Technologies Used
- Bash scripting
- Git and GitHub

## Purpose
This project demonstrates the basic calculation of simple interest using user-provided values.
